Instructions:

  1. Make sure js/secrets.js is a copy of js/secrets-blank.js and is filled out with all account info. These will be shown as a list of radio buttons to choose from.
  2. Select which account to authenticate
  3. Note the randomly generated data in the "state" textbox. This needs to match what Twitch returns to ensure your account information is safe, and protect against cross-site forgery requests.
  4. Click "Begin Authentication" button - this will copy the state value into your clipboard, which you will need to validate your login.
  5. Log into your Twitch account as normal- you will be redirected to a new local page.
  6. Paste the "state" textbox into the page Twitch returns you to.
  7. If the state matches, authentication was successful!
  8. If it does not match, try again. If it continually does not work, something unexpected is going on with the authentication process and you should probably consult a computer security expert.
